# CLAUDE.md

Telegram-based personal agent built on Vercel AI SDK + Convex + Composio.

## Run

```bash
# Terminal 1: Convex backend
npx convex dev

# Terminal 2: Server
npm run dev:server

# Test
curl -X POST http://localhost:3456/chat \
  -H 'Content-Type: application/json' \
  -d '{"conversationId":"my-boop","content":"hi"}'
```

## Commands

| Command | What it does |
|---------|-------------|
| `npm run dev` | Spawns server + Convex dev + Vite debug UI |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run start` | Production-like: `preflight && bun server/index.ts` |
| `npm run build:debug` | Vite build for debug dashboard |
| `npm run deploy:convex` | `convex deploy` |
| `npm run dev:server` / `dev:convex` / `dev:debug` | Run components individually |
| `npm run setup` | Interactive `.env.local` + Convex deployment setup |

**No tests exist — no linter.**

## Key structure

- **Server entry**: `server/index.ts` — Express + WS, loads integrations, starts background loops
- **Dispatcher**: `server/interaction-agent.ts` — routes messages, spawns sub-agents
- **Executor**: `server/execution-agent.ts` — ephemeral workers per task (uses Vercel AI SDK)
- **LLM layer**: `server/llm.ts` — provider-agnostic wrapper (OpenCode, OpenRouter, Ollama)
- **Telegram**: `server/telegram.ts` — bot handler via grammy
- **Convex schema**: `convex/schema.ts` — messages, memoryRecords, agents, automations, drafts, usageRecords
- **Memory pipeline**: `server/memory/` — extract.ts → clean.ts → consolidation.ts
- **Debug UI**: `debug/` — React + Vite + Tailwind

## PII safety (public repo)

Before staging **any** file, scan for:
- Personal contact info, live API keys, tokens
- Composio connection IDs (`ca_*`), OAuth state
- Real message content, production URLs, Telegram bot tokens
- Anything from `.env.local`

Substitute real values with generic placeholders before `git add`.

## LLM Providers

OpenCode Zen (free models), OpenRouter, or local Ollama. Configured via `.env.local`:

```
OPENCODE_API_KEY=sk-...
LLM_PROVIDER=opencode
LLM_MODEL=big-pickle
```

## Apple Calendar / Reminders (CalDAV)

Requires an app-specific password from [appleid.apple.com](https://appleid.apple.com) → Security:

```
APPLE_EMAIL=your@icloud.com
APPLE_APP_PASSWORD=xxxx-xxxx-xxxx-xxxx
```

The agent discovers `calendar` as an available integration slug. Spawn a sub-agent with `integrations: ["calendar"]` to read/create events and reminders.

## Docker (TrueNAS / production)

```bash
# 1. Deploy Convex functions to production
npx convex deploy

# 2. Update .env.local with the production CONVEX_URL shown after deploy

# 3. Build and run
docker compose up -d --build

# Or build manually:
docker build --build-arg CONVEX_DEPLOYMENT="https://your-project.convex.cloud" -t boop-agent .
docker run -d --env-file .env.local -p 3456:3456 boop-agent
```

See `compose.yml` and `Dockerfile` in the repo root.
